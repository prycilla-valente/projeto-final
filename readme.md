# Projeto Final - Git Flow

##  Sobre o Projeto

Este projeto foi desenvolvido para praticar os principais conceitos de Git e GitHub, simulando um fluxo de trabalho semelhante ao Git Flow.

O projeto consiste em um pequeno site com páginas Home, Sobre e Contato, desenvolvido utilizando HTML, CSS e JavaScript.

- GitHub

##  Fluxo de Branches

O projeto utiliza uma organização baseada no Git Flow.

- `main` → versão estável do projeto.
- `develop` → integração das funcionalidades.
- `feature/*` → desenvolvimento de novas funcionalidades.
- `release/*` → preparação para uma nova versão.
- `hotfix/*` → correções urgentes.
